# ApplyFlow

Ferramenta inteligente que reescreve seu currículo automaticamente para cada vaga, usando IA para aumentar suas chances de passar pelos filtros ATS.

🔗 **[Acesse o ApplyFlow](https://codevvitor.github.io/applyflow/)**

## Como usar

1. Acesse [Google AI Studio](https://aistudio.google.com) e gere sua chave de API gratuita
2. No arquivo `scripts/script.js`, substitua `SUA-KEY` pela sua chave na URL do fetch
3. Cole a descrição da vaga no primeiro campo
4. Cole o texto do seu currículo no segundo campo
5. Clique em **Analisar**
6. Receba seu currículo reescrito e otimizado

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Gemini API (Google AI)
